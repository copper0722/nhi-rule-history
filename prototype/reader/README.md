# Reader prototype

This static prototype exercises the human-facing contract in
`docs/reader-experience.md` with a real NHI Gilteritinib amendment.

It deliberately separates:

- the version effective today from a later announced version;
- complete text for the selected latest/effective version;
- immediate-successor diffs for older versions;
- verified adjacency from unresolved historical relationships.

The sample is not a public-data release and does not claim complete history.
It links back to the official NHI notice and ODT comparison table.
