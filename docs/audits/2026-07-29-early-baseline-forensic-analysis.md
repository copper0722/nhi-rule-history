# 84 年原始基線與 85/1/1 日期註記：偵探式版本考據

## 結論

1. **84 年原始全文已取得，不再是 `availability_unresolved`。** MOHW FINT
   以早期正式名稱「全民健康保險藥品使用規範」查得
   `健保醫字第84010140號`（84-06-20）；詳情頁明載附件二，且明示除特別
   規定外自 84-07-01 實施。
2. 官方附件是 25 頁、3,802,900 bytes 的掃描 PDF，SHA-256
   `f773cf6eeb9c413a92fae9bf543c5f1ff161726142fff802848292d00064b4d2`。
   原始檔沒有實質文字層；OCR 只能是待逐頁校對的 reconstruction，不能
   冒充官方 exact text。
3. **仍未找到 85/1/1 的精確修正文。** 條文句子搜尋為 0；五種日期寫法
   中四種為 0，`85/1/1` 的 11 筆命中逐筆檢視後均與本條修正無關。
   因此正確狀態是 `not_found_after_declared_search`，不是「公文不存在」。
4. 84 年掃描與 96 年整編檔已能建立 `0.7` 的 observation delta，但它仍
   不是一份已證實的單次 85 年修正公文。

## 84 年基線直接告訴我們什麼

掃描第 2–3 頁的「通則」共有一至八條。第七條原文在第 3 頁清楚可讀：

> 七、本保險處方用藥，以符合衛生主管機關核准之適應症為使用原則。

其後另有過渡處理文字，允許具臨床療效或原公、勞保曾同意給付的適應症向
分局申請，並要求藥商於公告後一年完成許可證適應症增列；逾期未經核准者
不予給付。

96 年 7 月版同號位置則是：

> 七、本保險處方用藥，需符合中央衛生主管機關核准藥品許可證登載之
> 適應症，並應依病情治療所需劑量，處方合理之含量或規格藥品。
> （85/1/1、86/1/1、94/6/1）

所以 84→96 至少發生過實質改寫；括號三個日期是找回中間版本的強索引，
但不能單靠日期序列把 84 與 96 之間切成三份 exact legal versions。

## FINT 為何「句子查不到、標題卻找得到」

宣告的 1995-01-01..1997-12-31 查詢結果如下：

| 查詢 | 結果 | 判讀 |
|---|---:|---|
| `本保險處方用藥` | 0 | FINT 沒有索引掃描附件內文 |
| `處方合理之含量或規格藥品` | 0 | 同上 |
| `全民健康保險藥品使用規範` | 2 | 找到 84 年原始公告及 86 年相關函釋 |
| `85/1/1` | 11 | 皆為日期 token 的無關公文 |
| 四種中文日期寫法 | 0 | 沒找到本條修正事件 |

這證明 FINT 的「詳情頁 metadata／公文正文索引」與「附件全文」不是同一個
搜尋面。後續搜尋不能只貼條文句子，也不能因句子零命中就排除公文；應先用
歷史法規名稱、文號、可能的公告主旨、成分／藥名與窄日期窗找 detail，再逐份
開附件。

## 條號穩定性的初步證據

- 84 年通則為一至八條；96 年觀察到一至十條，沒有內部跳號；現行再增至
  十二條。`0.7` 的主題與位置具有強連續性。
- 96 年全書以初步 decimal-heading extractor 取得 275 個條號；到 109 年
  仍可見其中 259 個（94.2%）。這只支持「條號通常穩定」，不是 identity
  規則。
- 反例已存在：`2.1.6`–`2.1.8` 後來移到 `2.1.1.5`–`2.1.1.7`，
  `9.9.1/9.9.2` 合併為 `9.9`，`10.7.2.2` 回到 `10.7.2`。因此條號消失
  不能直接寫成刪除；必須先記錄
  `appearance_observed / text_change_observed / disappearance_observed`，
  再由 identity lineage 判定 move、split、merge、delete 或 restore。

## 無日期的小項如何處理

96 年 acyclovir 條文中 `(4)`、`(5)` 無日期，而 `(6)` 帶
`（85/1/1）`。這只能表示日期 marker 附著在可見 span，不表示 `(4)`、
`(5)` 自 84 年起從未修改，也不表示它們在 marker 日期以前不存在。

98 年又將結構改成 `10.7.1`、`10.7.1.1`、`10.7.1.2`，原有小項大致延續，
同時新增局部抗疱疹病毒劑分支。這是典型的結構重排：全文與條號 ancestry
要同時比較，不能以單一日期或單一條號判定 identity。
